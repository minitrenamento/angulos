# Ângulos — Móveis Planejados

Landing page da Ângulos (Maputo, Moçambique): manutenção, reparação e medições
de móveis planejados.

- Página única, sem dependências ou build: `Angulos.html`
- Roupeiro 3D interativo em CSS — clicar numa porta ou gaveta marca o problema no formulário
- O pedido é enviado por WhatsApp para +258 88 060 1185
- Tema claro/escuro, responsivo

## Desenvolvimento

Abrir `Angulos.html` directamente no browser, ou servir a pasta:

    python -m http.server 4178

## Publicação

Alojado no Vercel. O `vercel.json` serve `Angulos.html` na raiz do domínio.
